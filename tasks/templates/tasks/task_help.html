{% trans "How do activities work?" %}
{% trans "Mine" %}

{% blocktrans %}The tab collects activities that directly concern you: activities that you have undertaken (you are the owner) and activities in which you have declared your help (you have clicked "I want to help").{% endblocktrans %}

{% trans "Pending" %}

{% blocktrans %}Activities that do not yet have an owner or have an owner but have not gathered enough support (the difference in votes "I want to help" minus "we are not doing this" is less than 2). Anyone can take such an activity using the "Take" button.{% endblocktrans %}

{% trans "In progress" %}

{% blocktrans %}Activities that have an owner and have collected at least 2 net declarations of help (votes "I want to help" minus votes against ≥ 2). The owner can resign - the activity then returns to the waiting list. Votes ≤ −2 automatically reject the activity.{% endblocktrans %}

{% trans "Completed" %}

{% blocktrans %}Activities closed by the owner (completed or canceled) and activities rejected by the community (total votes ≤ −2). A completed activity can be reopened.{% endblocktrans %}

{% trans "Declaration of aid" %}

{% blocktrans %}The "I want to help" button is a declaration of commitment - not a like. The number of people who clicked it is visible on the activity tile. Sufficient support (≥ 2 net) is a condition for the activity to be implemented.{% endblocktrans %}
