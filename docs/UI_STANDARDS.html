Wikikracja — Standardy UI

Ten dokument zbiera wspólne standardy wizualne aplikacji. Celem jest, aby jedna zmiana w komponencie (np. guzik CTA) propagowała się automatycznie we wszystkich modułach.

Każdy przykład poniżej jest żywym komponentem — można go otworzyć w przeglądarce, zrobić zrzut ekranu i użyć jako referencji w dokumentacji projektowej.

1. Kolory i tokeny

Podstawowe zmienne CSS są zdefiniowane w home/static/home/css/tokens.css.

akcent · badge-proposition · badge-approved · badge-rejected

2. Guziki podstawowe

Primary / Secondary / Warning / Danger

Każdy guzik powinien mieć ikonę. Ikona zawsze po lewej, tekst po prawej.

3. Guzik CTA (dodawanie treści)

Wspólny przycisk „dodaj” we wszystkich modułach
  • Zawsze okrągły, 22×22 px (ikona fa-plus pozostaje 1.1rem).
  • Zawsze ikona fa-plus w kółku.
  • Kolor tła: var(--accent).
  • Wszędzie ten sam komponent: home/templates/home/includes/toolbar.html.

4. Toolbar

Toolbar w module List / Grid
Date Score
  • Przełączniki widoków zawsze nazywają się List i Grid z ikonami fa-list i fa-grip.
  • Przyciski sortowania mają ikonę + etykietę + strzałkę kierunku.
  • Na małych ekranach etykiety przycisków nieaktywnych są ukryte, widoczna jest tylko aktywna.

5. Zakładki steppera

Stepper w Tasks / Głosowania / Obywatele
Mine
Awaiting
In progress
Finished
  • Każda zakładka ma ikonę i etykietę.
  • Na desktopie widoczne ikona + tekst.
  • Na mobile nieaktywne zakładki pokazują tylko ikonę; aktywna pokazuje ikonę + tekst.
  • Licznik (jeśli występuje) to .tw-stepper-step-count.

6. Liczniki na pulpicie

Activity i Chat tiles
0 3 unread
  • Jedna wspólna klasa: .tw-dashboard-counter-btn.
  • Gdy licznik = 0: przezroczyste tło, kolorowy tekst i obramowanie.
  • Gdy licznik > 0: wypełnione tło var(--badge-proposition-bg).
  • Zawsze ikona po lewej, wartość/tekst po prawej.

7. Kafelki pulpitu

Calendar Add event

Przykładowa zawartość kafelka.

  • Nagłówek kafelka to .tw-dashboard-tile-header + .tw-tile-heading.
  • .tw-tile-heading nie jest podkreślony, nawet gdy jest linkiem.
  • Kafelek używa klasy .tw-card.

8. Topbar (mobile)

Surveys
  • Na mobile nazwa modułu jest wyśrodkowana między logo a ikonami.
  • Logo po lewej, akcje po prawej.

9. Kafelki — widok listy i siatki

Description

Grid view
#2 Grid card one

Compact body text for grid layout.
#3 Grid card two
Discussion
Another compact card.
  • Karta składa się z klikalnego nagłówka i klikalnego ciała. Używaj atrybutu data-detail-url + role="link" na wrapperach, a linków wewnętrznych obsługuj przez onclick="event.stopPropagation()".
  • Nagłówek zawiera: numer, tytuł, badge status, meta (autor, data, liczniki).
  • Ciało zawiera sekcje z ikoną + etykietą + treścią.
  • Widok listy: karty jedna pod drugą w pionowej kolumnie (.tw-proposals-list).
  • Widok siatki: karty w CSS Grid — 1 col mobile, 2 col tablet, 3–4 col desktop (.tw-proposals-list.tw-view-grid).
  • W siatce karta jest kompaktowa, ale zachowuje ten sam nagłówek / badge / strukturę sekcji.
  • Dla konkretnych domen używaj dziedziczonych klas: .tw-board-post-card, .tw-proposal-card / .tw-task-card / .tw-event-card.

11. Pliki źródłowe

  • Toolbar: home/templates/home/includes/toolbar.html
  • Wspólny arkusz projektowy (komponenty + moduły + utilities, scalone w etapie 5.5): home/static/home/css/tailwind.css (kompilowany do tailwind.build.css przez npm run build:css)
  • Tokeny: home/static/home/css/tokens.css
  • Preferencje widoku: home/static/home/js/app.js

12. Zasady ogólne

  • Jeden komponent = jedno źródło. Jeśli guzik występuje w wielu miejscach, powinien korzystać z tego samego szablonu / klasy.
  • Ikona przy każdym guziku. Ikona po lewej, tekst po prawej (z wyjątkiem CTA w toolbarze, gdzie jest tylko ikona).
  • Responsywne etykiety. Mobile: nieaktywne guziki pokazują ikonę, aktywne ikonę + tekst.
  • CTA zawsze taki sam. Okrągły plus 22×22 px w toolbarze.
  • Widoki: List / Grid. Zawsze te same ikony i etykiety.
  • Zakładki: ikona + etykieta. Mobile nieaktywne tylko ikona.
  • Nie używaj lokalnych stylów inline. Preferuj klasy CSS i tokeny.
